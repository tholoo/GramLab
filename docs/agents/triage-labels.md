# Triage labels

Use these exact values in an issue's `Status:` line:

| Role | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation required |
| needs-info | More information required |
| ready-for-agent | Specified and ready for agent work |
| ready-for-human | Human implementation required |
| wontfix | Will not be actioned |

These are triage roles, not completion states.
