# Derive ordinary document filenames and MIME from pinned TDLib rules

Type: task
Status: ready-for-agent
Work state: open
Blocked by: none

Implement the pure metadata prerequisite for ordinary document uploads under the approved media
architecture. This does not close document API, automatic server classification or album support.
The source contract is [document references](../../../docs/development/documents-references.md).

## Ownership and interface

Own this ticket; new `src/gramlab/_document_metadata.py`; focused
`tests/test_document_metadata.py`; a bounded original/oracle fixture directory
`tests/fixtures/document_metadata/`; and `docs/development/tdlib-document-metadata-provenance.json`.
Coordinator owns World/HTTP/native changes, shared docs, lockfiles and CI. Do not edit other modules.

Expose `clean_document_filename(decoded_name: str) -> str` and
`document_mime_type(cleaned_filename: str) -> str`. The first receives an already decoded multipart
filename value, not a host path to open. Apply the exact pinned TDLib `clean_filename` behavior and
HTTP temporary-basename fallback `file`. The second returns the pinned extension-derived MIME
string, including the empty string for unknown/missing extensions. Do not infer type from bytes,
use the host MIME database, normalize case beyond the pinned source, or import the image decoder.
Multipart quoted-string/percent decoding belongs to later HTTP integration and is not this helper.

Pin TDLib `bc9c263e2bfee06aaab41e82db51a103376030bc`. Both slash kinds are PathView separators;
use the last dot strictly after the first basename character for extension splitting. Match stem
and extension emitted-character bounds, disallowed-character replacement, skipped normalization
characters, Unicode category membership and trimming exactly. Invalid UTF-8-representable strings
must follow the pinned empty-cleaned-name fallback; reject non-string API inputs clearly.

Reuse only the relevant BSL-1.0 TDLib algorithms/data with original attribution and the complete
license in the adapted module, following the existing emoji predicate precedent. Record exact
source hashes, generator inputs and reproduction. No GPL Android code/data belongs in this module.
Do not approximate pinned Unicode rules with the host Python Unicode version. If exact Unicode
predicates require generated data, bound the representation and preserve a reproducible generator
or independently verified source-derived table; request a scope clarification if a large source
import or new runtime dependency appears necessary. Existing LICENSES/BSL-1.0.txt stays unchanged.

## Acceptance and verification

Demonstrate behavior against an independently executed pinned reference or a reviewed literal
source-derived corpus, not expected values generated by the Python implementation. Cover path
separators, dotfiles, trailing dots, empty/invalid names, ASCII forbidden punctuation, Persian/RTL,
combining marks, supplementary characters, category boundaries and both truncation limits. Cover
unknown/no extension, mixed case, MIME-table aliases and declared-MIME independence at this pure
boundary. Retain clear counterexamples against plausible host-basename/MIME/Unicode substitutions.

Follow TESTING.md and the parallel workflow. Use the assigned checkout's pinned offline shell;
run focused tests, Ruff and strict mypy only. Reference source acquisition is permitted separately
from runtime execution, with locally discovered proxy settings if needed. Keep raw acquired source
and machine paths ignored. Do not clone/export Android, run a guest/build/full gate, modify HTTP
limits or implement file classification. Keep outputs bounded, retire disposable reference-build
outputs after preserving source hashes and oracle results, and freeze a clean commit with exact
Git hash and terminal process state for coordinator review.
